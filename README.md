# رزا

همراه آفلاین مراقبت از پوست، چرخه و ثبت روزانه، با رابط فارسی و راست‌چین.

## اجرای وب

```bash
npm ci
npm run dev
```

## ساخت اندروید

```bash
npm ci
npm run build
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
```

برای انتشار امضاشده، کلید امضا و تنظیمات Gradle را در محیط امن CI قرار دهید و قبل از انتشار، مجوزها و سیاست حریم خصوصی را بررسی کنید. آب‌وهوا تنها قابلیت آنلاین است؛ اطلاعات پوست، چرخه، عکس و ثبت‌های روزانه به سرویس ارسال نمی‌شوند.


## اعلان‌های اندروید

بعد از نصب وابستگی‌ها و ساخت پروژه Android، برنامه هنگام اولین ورود مجوز اعلان می‌گیرد و یادآوری روزانه روتین صبح ساعت ۹ و روتین شب ساعت ۲۱ را به‌صورت محلی زمان‌بندی می‌کند. اگر کاربر در بازه احتمالی پیش از قاعدگی باشد، یادآوری چرخه هم فعال می‌شود. هیچ متن یا داده شخصی به سرور اعلان ارسال نمی‌شود.
